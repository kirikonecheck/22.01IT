# Основы редактирования текста

## Курсор

Это простой текстовый файл

Курсор

`Home` - начало строки
`End` - конец строки

`PgUp` - в начало документа
`PgDown` - в конец документа

`Ctrl + >` - перемещение по слову вправо
`Ctrl + <` - перемещение по слову влево

## Сохранение

`Ctrl + S` - сохранение всего документа
`Ctrl + Z` - отмена последнего действия
`Ctrl + Y` - возврат последнего действия

## Выделение

`Ctrl+A` - выделить всё

`Ctrl + Shift + >` - выделение посимвольно вправо
`Ctrl + Shift + <` - выделение посимвольно влево
`Ctrl + Shift + вверх` - выделение посимвольно вверх
`Ctrl + Shift + вниз` - выделение посимвольно вниз

## Табуляция

`Tab` - отступ 2 или 4 пробела
